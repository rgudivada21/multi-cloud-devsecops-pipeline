# Multi-Cloud DevSecOps Pipeline

## Overview
A sample DevSecOps project demonstrating CI/CD, Docker, Terraform, Kubernetes, and Security Scanning across AWS, Azure, and GCP.

## Technologies
- Python (Flask)
- Docker
- GitHub Actions
- Terraform
- Kubernetes
- Trivy
- OWASP Dependency Check
- Prometheus
- Grafana
